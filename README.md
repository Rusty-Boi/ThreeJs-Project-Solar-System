# 🌌 Solar System Simulation (Three.js)

A real-time 3D solar system simulation built with Three.js using the WebGL Renderer. This project visualizes planetary motion with unique rotation and revolution speeds, calculated from speeded-up real-world astronomical data.

## 🎥 Demo
![Demo](https://github.com/user-attachments/assets/015def3e-568b-4a6d-8ef3-c0e2afe61bc7)

✨ Features

- ☀️ Complete Solar System Model
Includes the Sun and planets with accurate relative motion.

- 🔄 Realistic Planetary Motion
Each planet has:
  - Individual rotation speed (spin)
  - Individual revolution speed (orbit)

- ⏱ Time-Scaled Simulation
Real astronomical data is accelerated to allow visible motion in real time.

- 🧭 Orbit Visualization
Clear orbital paths for each planet.

- 🎥 Interactive 3D Camera
Users can explore the solar system from different angles.

- ⚡ WebGL Renderer
Optimized rendering using Three.js’ WebGLRenderer.

🛠 Tech Stack
- Three.js
- WebGL
- JavaScript (ES6+)
- HTML5
- CSS3
